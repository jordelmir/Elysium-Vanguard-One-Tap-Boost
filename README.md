**Elysium Vanguard** is a world-class, professional Android optimization suite designed for extreme performance. It leverages the **Shizuku API** to execute ADB-level system tweaks without root, providing a seamless "One Tap" experience to transform your device into a high-performance machine.

## 🚀 Core Features

- **Elite UI Logic**: 0.15s animation scales for instantaneous system response.
- **Hyper-Acceleration**: Direct SurfaceFlinger optimizations and GPU composition forcing.
- **Fixed Performance Mode**: Locks CPU/GPU clocks to prevent thermal throttling during intense tasks.
- **Cyberpunk Aesthetics**: Premium Jetpack Compose interface with glassmorphism and real-time telemetry arcs.
- **Multi-Device Intelligence**: Tailored optimizations for Samsung (GOS disabling, RAM Plus removal) and MediaTek (Helio G99) hardware.
- **Total Debloat**: Safely disables system-level bloatware via the Shizuku bridge.

## 🛠 Installation

1. Install **Shizuku** from the Play Store or GitHub.
2. Activate Shizuku via Wireless Debugging or Root.
3. Download the latest `ElysiumVanguard.apk` from the [Releases](link-to-releases) section.
4. Grant Shizuku permissions when prompted.
5. Tap the **Hexagonal Core** to engage Hyper-Acceleration.

## 🛡 Security & Privacy

- **Safe-to-Run**: Only uses official ADB/Command-line system APIs.
- **No Data Collection**: All optimizations are performed locally on-device.
- **Stealth Mode**: Disables developer option flags after application to maintain compatibility with banking apps.
